# Country boundary data

`countries.geojson` is the Natural Earth 1:50m Admin-0 Countries layer,
version 5.1.1. It was downloaded from the version-tagged
[`nvkelso/natural-earth-vector` GeoJSON export](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.1/geojson/ne_50m_admin_0_countries.geojson)
of Natural Earth's country dataset.

- License: public domain under [Natural Earth's terms of use](https://www.naturalearthdata.com/about/terms-of-use/).
- Upstream dataset description: [Admin-0 Countries](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries/).
- Coordinate reference: GeoJSON longitude/latitude in WGS84 (EPSG:4326).
- Upstream SHA-256: `3e458fc036ad0a66411f2c1e6cac49c5d7bfb81cb1123bc513b22511a2b7fdeb`.

Natural Earth renders de facto boundaries by default. Its generalized 1:50m
coastlines and borders are suitable for a local map and approximate track
annotation, not legal, navigation, or authoritative sovereignty decisions.
Some territories without a valid ISO alpha-2 code are not resolvable by country
code. An uncertain or unresolved result must not be converted to a positive
country alert.
